# MyGym 🏋️‍♂️

تطبيق **MyGym** هو تطبيق متكامل ومتعدد المنصات (Web, Mobile, Desktop) يهدف إلى إدارة التمارين الرياضية، تتبع الجلسات، وإنشاء روتينات مخصصة للياقة البدنية. تم تصميم التطبيق ليكون عصرياً، سريعاً، وسلساً في الاستخدام، مع دعم لميزات الذكاء الاصطناعي.

## ✨ المميزات الرئيسية
- **إدارة التمارين والروتين:** إنشاء وتخصيص وتتبع روتينات التمارين الرياضية الخاصة بك.
- **سجل الجلسات (Sessions):** تتبع دقيق لكل جلسة تمرين وتقييم الأداء.
- **متعدد المنصات:** يعمل بسلاسة كـ تطبيق ويب (PWA)، تطبيق هواتف ذكية (iOS و Android)، وتطبيق سطح مكتب (Windows/macOS).
- **مدعوم بالذكاء الاصطناعي:** دمج تقنيات Google GenAI لتقديم استشارات أو تحليل للتمارين.
- **مزامنة سحابية:** حفظ ومزامنة بياناتك بأمان باستخدام Firebase.

---

## 🛠️ التقنيات والأدوات المستخدمة

تم بناء المشروع باستخدام أحدث التقنيات وأفضل الممارسات في تطوير التطبيقات:

### 💻 اللغات وإطارات العمل (Frontend)
- **[React (v18)](https://reactjs.org/):** مكتبة واجهة المستخدم الأساسية.
- **[TypeScript](https://www.typescriptlang.org/):** لغة البرمجة الأساسية لضمان جودة الأكواد وخلوها من الأخطاء.
- **[Vite](https://vitejs.dev/):** أداة بناء وسيرفر تطوير فائقة السرعة.
- **[React Router (v6)](https://reactrouter.com/):** لإدارة التنقل والصفحات (Routines, Sessions, Settings, إلخ).

### 🎨 التصميم وتجربة المستخدم (UI/UX)
- **[Tailwind CSS (v4)](https://tailwindcss.com/):** إطار عمل التصميم الأساسي لبناء واجهات متجاوبة وعصرية.
- **[Framer Motion](https://www.framer.com/motion/):** لإنشاء حركات (Animations) وانتقالات سلسة بين العناصر والصفحات.
- **[Lucide React](https://lucide.dev/):** مكتبة أيقونات عصرية ومتناسقة.
- **`clsx` & `tailwind-merge`:** لإدارة ودمج الكلاسات (Classes) بشكل ديناميكي.

### ☁️ قواعد البيانات والخدمات الخلفية (Backend/BaaS)
- **[Firebase (v12)](https://firebase.google.com/):** لخدمات الواجهة الخلفية، وتحديداً:
  - **Cloud Firestore:** لتخزين بيانات المستخدمين، التمارين، والروتين بشكل حي (Realtime).
  - تم استخدام إعدادات الأمان (Firestore rules) لحماية البيانات.

### 📱 المنصات المتعددة (Cross-Platform)
- **[Capacitor](https://capacitorjs.com/):** لتحويل تطبيق الويب إلى تطبيق هواتف أصلية (Android و iOS).
- **[Electron](https://www.electronjs.org/):** لتشغيل التطبيق كبرنامج سطح مكتب مستقل.
- **PWA (Progressive Web App):** باستخدام إضافة `vite-plugin-pwa` لدعم العمل دون اتصال (Offline) وتثبيت التطبيق من المتصفح.

### 🤖 ميزات إضافية
- **الذكاء الاصطناعي:** الاعتماد على مكتبة `@google/genai` (Gemini API) لدمج ميزات الذكاء الاصطناعي مثل تحليل الأداء أو توليد الروتينات.
- **إدارة التواريخ:** استخدام `date-fns` للتعامل مع التواريخ والأوقات بسلاسة.
- **React Markdown:** لعرض النصوص المنسقة (Markdown) وربما لعرض ردود الذكاء الاصطناعي بشكل مقروء.

## 🚀 كيفية التشغيل والتطوير (Development)

تأكد من تثبيت [Node.js](https://nodejs.org/) على جهازك.

1. **تثبيت الحزم (Dependencies):**
   ```bash
   npm install
   ```

2. **تشغيل بيئة التطوير للويب (Web):**
   ```bash
   npm run dev
   ```

3. **تشغيل بيئة التطوير لسطح المكتب (Electron):**
   ```bash
   npm run electron:dev
   ```

4. **بناء المشروع للإنتاج (Production):**
   ```bash
   npm run build
   ```

5. **تحديث ومزامنة تطبيق الهاتف (Capacitor):**
   ```bash
   npm run cap:sync
   ```

## 📂 هيكلية المشروع الأساسية
- `src/`: يحتوي على جميع ملفات المصدر (Components, Views, Services).
  - `views/`: صفحات التطبيق الرئيسية مثل `TodayView`، `RoutinesView`، `SettingsView`.
- `electron/`: يحتوي على ملفات وإعدادات تطبيق سطح المكتب.
- `android/` & `ios/`: ملفات تطبيقات الهواتف الذكية المُدارة عبر Capacitor.
- `firestore.rules`: قوانين الوصول والأمان لقاعدة بيانات Firebase.
